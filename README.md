💄 Dashboard de Análise de Dados – Opuline Cosméticos
🏢 Sobre a Empresa
A Opuline é uma empresa que atua no setor de cosméticos desde 2022. Até o momento, seus processos ainda não são orientados por dados, mas agora ela quer dar um passo importante rumo à cultura Data Driven — e é aqui que entramos! 🚀

🎯 Objetivo do Projeto
Nosso papel é ajudar a Opuline a iniciar sua transformação digital por meio de análises visuais bem construídas no Power BI, com foco em:

📊 Criação de gráficos e visuais adequados para cada tipo de análise

📈 Construção de KPIs, indicadores e painéis interativos

🔍 Implementação de navegação entre páginas, filtros dinâmicos e parâmetros

💬 Geração de insights que agregam valor real ao negócio, indo além da estética visual

🧠 O que aprendemos?
✅ Visualizações com Propósito
Aprenderemos como escolher o gráfico certo para cada análise, como criar indicadores eficientes e como interpretar os dados visualmente com clareza e impacto.

✅ Filtros e Navegação
Trabalharemos com elementos que tornam o relatório interativo e flexível:

Filtros visuais

Parâmetros de análise

Botões de navegação entre páginas

✅ Apresentações com Insights
Algumas páginas terão um estilo mais apresentação executiva, com visuais estáticos acompanhados de textos explicativos e insights prontos para tomada de decisão.

🗂️ Estrutura das Tabelas
O modelo de dados foi organizado de forma clara, seguindo boas práticas de modelagem dimensional:

🔹 Tabelas de Dimensão (d)
dMarcas: Marcas dos produtos

dProdutosFinais: Lista de produtos disponíveis

dCategoriasProdutos: Agrupamentos por categoria

🔸 Tabelas de Fato
fPedidos: Registro de pedidos realizados

Calendario: Tabela de datas, fundamental para análises temporais

dMetaMensal: Metas comerciais por mês

🌟 Destaques do Projeto
Integração de visuais dinâmicos e estáticos

Construção de um relatório interativo e executivo no Power BI

Apoio à cultura Data Driven da Opuline com base em dados reais

Visualizações que informam e encantam

🛠️ Tecnologias Utilizadas
Microsoft Power BI

Power Query

DAX
